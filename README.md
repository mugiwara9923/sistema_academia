# Sistema de Academia

Sistema de gerenciamento de academia desenvolvido em Dart como atividade acadêmica.

## Sobre o projeto

O sistema foi desenvolvido para realizar o gerenciamento básico de uma academia, permitindo cadastrar e consultar informações de alunos, planos, modalidades, instrutores, matrículas e acessos.

O projeto utiliza conceitos de programação orientada a objetos, listas, estruturas de repetição, condicionais, validações, datas e relacionamentos entre classes.

## Funcionalidades

- Cadastro de alunos
- Listagem de alunos
- Alteração de dados de alunos
- Exclusão de alunos
- Cadastro de planos
- Listagem de planos
- Cadastro de modalidades
- Listagem de modalidades
- Cadastro de instrutores
- Listagem de instrutores
- Cadastro de matrículas
- Listagem de matrículas
- Registro de acesso dos alunos
- Listagem de acessos
- Relatório de matrículas vencidas
- Relatório de acessos por período
- Validação de dados
- Cálculo da data de vencimento das matrículas

## Entidades

O sistema possui as seguintes entidades:

- Aluno
- Plano
- Modalidade
- Instrutor
- Matrícula
- Acesso

## Como executar

É necessário ter o Dart SDK instalado.

Clone o repositório:

```bash
git clone https://github.com/mugiwara9923/sistema_academia.git

ENTRE NA PASTA DO PROJETO
cd sistema_academia

EXECUTE O SISTEMA
dart run bin/sistema_academia.dart

Objetivo

O objetivo do projeto é aplicar na prática conceitos aprendidos durante a disciplina, utilizando a linguagem Dart para desenvolver um sistema de gerenciamento simples executado pelo terminal.
